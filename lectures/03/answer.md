## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  同じ質問「AIE2026の講座の宿題にある「3レベル」とは何ですか？」で比べた。
  第1回の `app.ask` は、講座の情報を持たないため「AIの活用レベル」「課題の難易度（レベル1〜3）」など複数の可能性を並べ、最後は「Slack や講師に確認してください」と案内して、答えを特定できなかった。

- `--trace` で見えたツール呼び出し（ツール名と引数）：
  - 「LoRAとQLoRAの違いは？」：`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})`。用語を1つずつ別々に検索していた（`search_glossary` の docstring に「query には調べたい用語を1つだけ入れる」と書いてあるため）。
  - 「3レベル」の質問：`search_glossary({'query': '3レベル'})` の1回。
  - 「第2回の内容から確認問題を1問出して」：`make_quiz({'lecture': 2})` の1回。
- 1つの質問での LLM 呼び出し回数（`requests`）：
  - LoRAとQLoRAの質問：2（ツール呼び出し2回を並べて行い、結果を受けて回答を作った）
  - 3レベルの質問：2（ツール呼び出し1回）
  - 確認問題の質問：2（ツール呼び出し1回）
  - ツールを呼ぶ質問は、「ツールを呼ぶ」と「結果を見て回答する」で、LLM を2回呼ぶ形になっていた。
- 追加したツールと、docstring に書いた説明：
  `app/tools.py` に `make_quiz(lecture: int) -> str` を追加し、`app/agent.py` で `agent.tool_plain(tools.make_quiz)` として登録した。
  docstring は「指定した回の用語から1つを選び、確認問題と答えを返す。『第2回の確認問題を出して』のように、復習用の問題を求められたときに使う。lecture には回の番号（1始まりの整数）を入れる。」。
  用語集から `lecture` が一致する用語を集めて `random.choice` で1つ選び、`{"question": "「○○」の意味は？", "answer": <definition>}` を JSON 文字列で返す。該当する用語がない回（`make_quiz(99)` など）は「第99回の用語は用語集にありません。」と返す。
  確認：`--list-tools` に `make_quiz` と docstring が表示され、`--trace` で `make_quiz({'lecture': 2})` が呼ばれ、`uv run pytest -q` は 15 passed だった。
