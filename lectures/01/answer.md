# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：

AIE2026（AIエンジニア育成プログラムや関連するAI講座など）の宿題における「3レベル」という言葉ですね。

具体的な講座のシラバスや直近の講義内容によって若干ニュアンスが異なる場合がありますが、AI・プログラミング初学者向けの講座やAIEの課題において「3レベル」と言った場合、通常は**「宿題（または課題）の難易度や取り組み方の3段階」**を指しています。

多くの場合、以下のような構成になっています。

### 一般的な「3つのレベル」の分類

1. **レベル1（基礎・基本：Basic / Beginner）**
   * **内容:** 授業でやったコードをそのまま動かす、穴埋め問題を解く、基本的な用語を確認するなど。
   * **目的:** まず手を動かして環境構築や基本操作に慣れること。

2. **レベル2（応用・実践：Intermediate / Practical）**
   * **内容:** 少し条件を変えて自分でコードを書く、別のデータに当てはめてみる、エラーを自分で調べて解決するなど。
   * **目的:** 知識を定着させ、自力で動かす力をつけること。

3. **レベル3（発展・挑戦：Advanced / Challenge）**
   * **内容:** 応用問題にプラスして独自の機能を追加する、発展的な課題に挑む、より効率的なコードにリファクタリングするなど。
   * **目的:** さらに高いスキルを目指す人向けの挑戦枠。

---

### ※もし別の文脈の場合
もし「難易度」ではなく、AIの技術やプログラミングの概念としての「3レベル」を指している場合は、以下のような可能性もあります。

* **AI・機械学習の理解度レベル:** （例：①APIを使うだけ、②既存のモデルを微調整するファインチューニング、③ゼロからモデルを構築する）
* **プログラミングの習得レベル:** （例：①読める、②書ける、③教えられる・応用できる）

**確実な確認方法：**
もしお手元の課題資料やSlackなどのコミュニティに「3レベル」の具体的な説明（Level 1, Level 2, Level 3など）が記載されているページがあれば、その内容に沿って取り組むのが一番確実です。もし分からなければ、講座の講師やメンター、同期の受講生に「今回の宿題の3レベルとは、具体的にどこまでの範囲を指しますか？」と質問してみることをお勧めします！

## 宿題

- 取り組んだレベル：基礎 / 実装 / 発展：実装
- やったこと：
  - `app/ask.py` に `--chat` オプションを追加し、会話履歴を保ったまま続けて質問できる対話モードを実装した
  - 履歴は `types.Content`（role: user / model）のリストとして手元で管理し、毎回の質問に直近5往復分だけを付けて送るようにした
  - 送った履歴の往復数とトークン数を毎回表示するようにした
  - この実装に対して何度かAIと会話のラリーを行った。一番最初に名前を含めた自己紹介を行い、６ラリー目で自分の名前を覚えているかを尋ねた。
- 結果：
  - `--chat` なしで1回ずつ実行すると、毎回「送った履歴 0 往復」となり、名前を聞いても「わかりません」と答えた
  - `--chat` で続けて質問すると、前の発言を踏まえて答えた
  - 6回目の質問で名前を聞くと、1往復目が送る範囲から外れていたため「教えていただいていない」と答えた
  - 入力トークンは 9 → 55 → 196 → 547 → 629 → 771 と増え、5往復に達した後は 900 前後で頭打ちになった
- 気づき・疑問：
  - LLM自体は会話を覚えておらず、「会話の記憶」は毎回履歴を送り直すことで実現していると分かった
  - 履歴を送る分だけ入力トークンが増えるため、長い会話ではコストやレート制限に影響する。往復数で切ると古い情報（名前など）を忘れてしまう
